# CodeAlpha - URL Shortener - Task 1

Made by Rajnish | CodeAlpha Internship

## Features
- Paste long URL, get short link
- Click on short link to redirect to original URL
- Click tracking (Clicks count)
- Copy button
- Shows all links in table

## How to Run
1. npm install
2. npm start
3. Open http://localhost:3000

## Tech Used
Node.js, Express.js, HTML, CSS
